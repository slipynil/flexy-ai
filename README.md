# flexy_service

Телеграм-бот для генерации изображений через [flexy-ai.com](https://flexy-ai.com) с автоматической фермой аккаунтов: бот сам регистрирует аккаунты, подтверждает почту и распределяет нагрузку между ними.

## Возможности

- 🤖 **Телеграм-бот** — отправляешь фото, получаешь сгенерированное изображение (context2img); просто фото — со стандартным промптом, `/context` — изменение по твоему описанию (`/help` — справка)
- 🔄 **Ротация аккаунтов** — каждый запрос берёт наименее недавно использованный свободный аккаунт (round-robin)
- ⏳ **Cooldown** — при rate-limit со стороны API аккаунт исключается из ротации на 2 минуты, запрос автоматически уходит на следующий
- 🧵 **Параллельная генерация** — генерация выполняется в отдельных потоках, бот не блокируется
- 🏭 **Ферма аккаунтов** — авто-регистрация на flexy-ai.com с одноразовой почтой temp-mail.org (через undetected-chromedriver, обходит Cloudflare)
- 👤 **Регистрация без почты (ADR-003)** — pure requests, без браузера: сервис больше не проверяет email
- 💾 **Пул аккаунтов в SQLite** — лимиты генераций (tries), cooldown, потокобезопасный доступ

## Быстрый старт

Нужен [mise](https://mise.jdx.dev/) (он сам поставит Python 3.12 и poetry) и Chrome/Chromium.

```bash
# 1. Токен бота
cp .env.example .env
# впиши в .env токен от @BotFather

# 2. Запуск телеграм-бота (поставит зависимости сам)
mise run bot

# 3. Накопить аккаунты для пула
mise run register_accounts -- --counts 5
```

## Задачи mise

| Команда | Что делает |
|---|---|
| `mise run ui` | **Интерактивное меню** — бот, генерации, регистрация (рекомендуется) |
| `mise run bot` | Запуск телеграм-бота |
| `mise run register_accounts -- --counts N` | Регистрация N аккаунтов (temp-mail + браузер) |
| `mise run register_accounts_no_email -- --counts N` | Регистрация N аккаунтов без почты и браузера (ADR-003) |
| `mise run generate_txt2img -- --prompt "..."` | Разовая генерация текст→картинка |
| `mise run generate_ctx2img -- --imagepath file.jpg` | Разовая генерация картинка→картинка |
| `mise run setup` | Создать папки `data/` и `data/generated/` |
| `mise run install` | Пересоздать `./venv` и установить зависимости из `poetry.lock` |

│   ├── run_generate_txt2img.py   # CLI: текст → изображение

│   ├── farm.py               # ферма регистрации аккаунтов (ADR-001 фаза 2)

│   ├── generate_username.py  # генерация логинов

## Полезно знать

- Аккаунт даёт **3 генерации** (`tries`); когда они кончаются, аккаунт выпадает из пула
- API временно блокирует аккаунт при частых запросах — бот сам переключается на другой
- `chromedriver` скачивается и патчится `undetected-chromedriver'ом` автоматически, держать его в репозитории не нужно
- Схема БД мигрирует автоматически при запуске — пересоздавать `data/data.db` не требуется
